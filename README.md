# EntryNote

**EntryNote** is a cross-platform personal workspace for notes, task lists, vocabulary tables, recipes, and structured knowledge organization across Android, iOS, Windows, Linux, and macOS. Built with Flutter, the application combines an offline-first local database with seamless cross-device cloud synchronization and privacy-focused storage.

## Overview

Designed for fast, distraction-free organization, EntryNote keeps your entire workspace available offline without relying on external database servers. Everything lives inside a lightweight local SQLite engine, ensuring instant startup, zero latency while editing, and complete ownership of your files across both desktop and mobile devices.

## Key Features

**Hierarchical Organization** allows you to structure notes inside nested category trees, making it easy to separate personal journals, study vocabularies, checklists, and reference materials.

**Rich Content and Attachments** support structured notes, task tracking, custom vocabulary tables, and embedded file attachments that remain accessible even without an internet connection.

**Cross-Device Google Drive Sync** keeps your mobile and desktop workspaces aligned through your personal Google Drive account. When edits happen offline on multiple devices simultaneously, EntryNote safely resolves conflicts by preserving your local changes, keeping earlier Drive revisions intact, and isolating differing cloud entries into a dedicated copies folder so no data is ever overwritten.

**Privacy and Encryption** protect sensitive entries with client-side encryption keys. If conflicting keys are ever detected across synced devices, separate versions are safely maintained until the conflict is resolved.

**Multi-Language Support** provides a clean, responsive interface tailored for both English and Ukrainian workflows.
